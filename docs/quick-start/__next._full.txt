1b:T60ab,<p>sluglist is a framework-agnostic, dependency-light widget that lets people leave visual feedback
directly on a running web app: pick an element, grab an area or the full page, annotate the
screenshot, add a comment — and the widget produces a standard set of artifacts and hands them to
pluggable <strong>connectors</strong>. The core knows nothing about where feedback is stored; delivery is fully
encapsulated in the connector you provide.</p>

<h3>4 · Agent to agent — the loop runs itself</h3>
<p>A QA agent walks the checklist in a real browser and writes evidence-backed verdicts; a fix agent
answers them; a re-test round closes the loop.</p>
<pre class="shiki shiki-themes light-plus dark-plus" style="--shiki-light:#000000;--shiki-dark:#D4D4D4;--shiki-light-bg:#FFFFFF;--shiki-dark-bg:#1E1E1E" tabindex="0"><code><span class="line"><span style="--shiki-light:#795E26;--shiki-dark:#DCDCAA">npx</span><span style="--shiki-light:#A31515;--shiki-dark:#CE9178"> sluglist</span><span style="--shiki-light:#A31515;--shiki-dark:#CE9178"> init</span><span style="--shiki-light:#0000FF;--shiki-dark:#569CD6"> --agents-md</span><span style="--shiki-light:#008000;--shiki-dark:#6A9955">   # the four skills, PROJECT.md, .gitignore rules</span></span>
<span class="line"><span style="--shiki-light:#795E26;--shiki-dark:#DCDCAA">npx</span><span style="--shiki-light:#A31515;--shiki-dark:#CE9178"> sluglist</span><span style="--shiki-light:#A31515;--shiki-dark:#CE9178"> status</span><span style="--shiki-light:#0000FF;--shiki-dark:#569CD6"> --json</span><span style="--shiki-light:#008000;--shiki-dark:#6A9955">      # green | continue | stalled | blocked</span></span></code></pre><p>Nothing in your app changes — the QA agent writes the same artifacts through the headless writer,
<code>sluglist/node</code>. See <a href="/for/agent-loop/">the autonomous QA loop</a>.</p>
