<h2>What PII protection actually means here</h2>
<ul>
<li><strong>Screenshots:</strong> every input, textarea and select is redacted before the render; anything marked
<code>data-private</code> is always redacted. The live DOM is untouched — masking happens only in the
rendered image.</li>
<li><strong>Text:</strong> emails → <code>[email]</code>, long digit runs → <code>[digits]</code>, hex/base64 tokens → <code>[token]</code> —
across element text, URLs, error messages and the action trail. Dates, versions and stack-trace
line numbers survive, so reports stay readable.</li>
<li><strong>The trail records facts, not content:</strong> typing is logged as a character count; password fields
aren&#39;t logged at all; navigation paths drop the query string.</li>
<li><strong>Collected automatically:</strong> URL path, viewport, browser/OS, timezone, color scheme, recent
errors. <strong>Deliberately not collected:</strong> full user agent, IP, cookies, storage, geolocation.</li>
</ul>
<h2>Your infrastructure, not ours</h2>
<p>There is no sluglist server. Reports go to <a href="/docs/connectors/">connectors you configure</a> — the
recommended shape is a ~50-line API route in front of your own storage, holding the credentials
server-side. The widget makes no other network requests, and that claim is enforced by an automated
test.</p>
<h2>It cannot break your app</h2>
<p>Everything the widget wraps (<code>fetch</code>, <code>console.error</code>, <code>history</code>) always calls the original;
after repeated internal failures it uninstalls itself and gets out of the way. Undelivered reports
persist in an IndexedDB outbox and retry on the next load.</p>
<h2>Real users, real languages</h2>
<p>Label bundles ship for English, Russian, Ukrainian, Spanish and German — one line to apply, with
correct plural rules. Your own copy (categories, checklist titles, form labels) stays yours.
See <a href="/docs/production/">Localization</a>.</p>
<h2>Then what?</h2>
<p>A user report is the same artifact a teammate or an agent produces, so it drops straight into the
<a href="/for/local-dev/">fix loop</a>: pull the session folder into the repo and the agent reads it exactly as
if you had clicked it yourself.</p>
<h2>Before you ship</h2>
<p>Walk the <a href="/docs/production/">production checklist</a>: env gating, a delivery token, server-side
validation, retention, and a privacy-policy paragraph to adapt.</p>
