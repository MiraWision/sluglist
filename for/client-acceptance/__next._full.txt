<h2>Generate the checklist from the branch</h2>
<p>Don&#39;t write the list by hand: the bundled <code>sluglist-checklist</code> skill turns the branch diff into a
client-facing checklist — user-visible changes only, phrased for a non-developer. See
<a href="/docs/checklist/">Checklist mode</a>.</p>
<h2>Send back one file, not a folder</h2>
<pre class="shiki shiki-themes light-plus dark-plus" style="--shiki-light:#000000;--shiki-dark:#D4D4D4;--shiki-light-bg:#FFFFFF;--shiki-dark-bg:#1E1E1E" tabindex="0"><code><span class="line"><span style="--shiki-light:#795E26;--shiki-dark:#DCDCAA">npx</span><span style="--shiki-light:#A31515;--shiki-dark:#CE9178"> sluglist</span><span style="--shiki-light:#A31515;--shiki-dark:#CE9178"> report</span></span></code></pre><p>The session becomes a single self-contained HTML file: what passed, what failed, the fact observed
behind each verdict, every screenshot inlined. It opens offline, forwards as one attachment, and
prints to PDF cleanly — the artifact a client can actually read. See <a href="/docs/artifacts/">Reports</a>.</p>
<h2>Built for non-technical reviewers</h2>
<ul>
<li>Flagging a problem takes a comment and an automatic screenshot; annotation (arrow, box, text) is
right there.</li>
<li><strong>Smart links</strong> navigate the reviewer to the page under test; wildcard matches light up &quot;You&#39;re
here&quot; on dynamic routes.</li>
<li>The checklist panel is fully usable on a phone.</li>
<li>Reporter <a href="/docs/capture/">form fields</a> can ask what only they know (device, severity, which
account).</li>
<li>They can <a href="/docs/capture/">attach their own files</a> — a phone screenshot usually arrives via paste.</li>
</ul>
<h2>Where the feedback goes</h2>
<p>Through <a href="/docs/connectors/">a connector you own</a> — an API route in front of Vercel Blob, S3/R2 or
Supabase Storage is ~50 lines. No sluglist account, no third-party inbox holding your client&#39;s
screenshots.</p>
<p>The same checklist can be walked by <a href="/for/agent-loop/">a QA agent</a> instead of a person when you want
a pass before the client sees it — the artifacts are identical either way.</p>
