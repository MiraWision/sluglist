<h2>Use it while you work</h2>
<p>Click the launcher (or press <kbd>Shift</kbd>+<kbd>F</kbd>), pick an element, type what is wrong.
Every issue arrives as a folder of plain files:</p>
<pre class="shiki shiki-themes light-plus dark-plus" style="--shiki-light:#000000;--shiki-dark:#D4D4D4;--shiki-light-bg:#FFFFFF;--shiki-dark-bg:#1E1E1E" tabindex="0"><code><span class="line"><span>.sluglist/session-2026-08-16-a1b2/</span></span>
<span class="line"><span>  session.yaml</span></span>
<span class="line"><span>  01-save-does-nothing.md          # frontmatter + your comment + ## Errors + ## Actions</span></span>
<span class="line"><span>  01-save-does-nothing.png</span></span></code></pre><p>When a bug needs a sequence, <strong>record mode</strong> captures a screenshot per click and navigation, so the
report carries steps-to-reproduce as numbered frames instead of a sentence you have to write.</p>
<h2>Hand it to the agent</h2>
<pre class="shiki shiki-themes light-plus dark-plus" style="--shiki-light:#000000;--shiki-dark:#D4D4D4;--shiki-light-bg:#FFFFFF;--shiki-dark-bg:#1E1E1E" tabindex="0"><code><span class="line"><span style="--shiki-light:#795E26;--shiki-dark:#DCDCAA">npx</span><span style="--shiki-light:#A31515;--shiki-dark:#CE9178"> sluglist</span><span style="--shiki-light:#A31515;--shiki-dark:#CE9178"> init</span><span style="--shiki-light:#008000;--shiki-dark:#6A9955">       # skills, .sluglist/checklists/, .gitignore rules, PROJECT.md</span></span></code></pre><p>Then tell Claude Code <em>&quot;read feedback and fix it.&quot;</em> The bundled <code>sluglist-fix</code> skill reads each
issue, looks at the screenshot, localizes by component and selector, fixes the code, and records the
